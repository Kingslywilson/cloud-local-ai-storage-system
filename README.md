# Gradious AI-Enhanced Cloud File Storage & Sharing Platform

A full-stack, secure cloud storage web platform featuring AI-driven document, image, audio, and video content analysis using **Google Gemini 3.6 Flash**, automatic smart tagging, granular user isolation, folder management, unpredictable token-based public and specific-user file sharing, storage analytics, and comprehensive activity audit logging.

---

## 1. Project Overview
The **Gradious AI-Enhanced Cloud File Storage & Sharing Platform** provides users with secure, seamless cloud file management coupled with generative AI intelligence. Users can upload, organize, search, filter, preview, share, and manage personal files while receiving automated summaries, descriptions, smart tags, and content insights generated by Google Gemini 3.6 Flash.

---

## 2. Problem Statement
Traditional cloud file storage solutions often store files as static binary objects without understanding their underlying contents. Users struggle to manually categorize documents, recall file details, or extract insights from large text, media, and code files. Furthermore, insecure sharing mechanisms exposing file database IDs introduce severe vulnerability vectors. This project addresses these challenges by integrating Generative AI analysis, resilient error handling, unpredictable share token security, and audit logging.

---

## 3. Objectives
- **Secure File Management**: Enable fast, validated file upload, download, renaming, moving, and deletion.
- **Generative AI Integration**: Automatically extract text/multimodal content and generate rich AI summaries, descriptions, tags, and insights.
- **Privacy & Isolation**: Ensure complete user data isolation across files, folders, share records, and activity histories.
- **Unpredictable Token File Sharing**: Support public and specific-user sharing using unpredictable secure random tokens (`uuid4().hex`).
- **Real-Time Storage Dashboard & Audit Logging**: Provide dynamic storage capacity analytics and log every major action (`UPLOAD`, `DOWNLOAD`, `VIEW`, `DELETE`, `RENAME`, `MOVE`, `SHARE`, `LOGIN`, `LOGOUT`, `FOLDER` ops).

---

## 4. Features
- **User Authentication**: Registration, Login, Logout, JWT bearer token authentication, bcrypt password hashing.
- **File Operations**: Upload, view metadata & media preview, download, rename, move to folder, search (case-insensitive), filter by type (Documents, Images, Videos, Audio, Code).
- **Folder Management**: Create folder, rename folder, view folder contents, delete folder (safely unassigns contained files to root storage).
- **Secure Sharing**: Generate public or recipient-restricted share links; enforce recipient email verification; revoke active links instantly.
- **Dynamic Storage Usage**: Real-time total, used, remaining storage statistics and category byte breakdowns.
- **Activity Log**: Full chronological history of user actions displayed on `activity.html`.
- **Generative AI**: Automatic analysis of documents (PDF, DOCX, TXT, CSV, JSON, MD, Code), images, audio, and video using Gemini 3.6 Flash.

## 8. Frontend Setup
The frontend is built using standard Vanilla Web Technologies (no Node build step required).
To serve locally using Python:
```bash
cd Frontend
python -m http.server 5500
```
Application Address: `http://127.0.0.1:5500`

---

## 9. Backend Setup
1. Open terminal in the project directory.
2. Install Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Navigate to `Backend/` directory:
   ```bash
   cd Backend
   ```
4. Launch FastAPI server with Uvicorn:
   ```bash
   uvicorn main:app --host 127.0.0.1 --port 8000 --reload
   ```

---

## 10. MySQL Setup
1. Ensure MySQL Server is running on localhost port `3306`.
2. Create database:
   ```sql
   CREATE DATABASE IF NOT EXISTS gradious_cloud;
   ```
3. Tables (`users`, `folders`, `files`, `file_shares`, `ai_analysis`, `activity_logs`) are automatically created by SQLAlchemy ORM on backend startup (`Base.metadata.create_all`).

---

## 11. Gemini API Setup
1. Obtain an API Key from [Google AI Studio](https://aistudio.google.com/).
2. Place key in your `.env` file:
   ```env
   GEMINI_API_KEY=AIzaSy...
   ```
3. The backend utilizes `gemini-3.6-flash` for automatic text and multimodal (image, audio, video) processing. If no key is provided, the backend falls back gracefully without crashing file uploads.

---

Copy `.env.example` to `.env`:

## 14. API Overview
- `POST /auth/register` - Register user account
- `POST /auth/login` - Authenticate user & get JWT token
- `POST /auth/logout` - Log out session
- `GET /auth/me` - Profile information
- `GET /files/` - List user files (with search `?q=...`)
- `POST /files/upload` - Upload file & perform AI analysis
- `GET /files/{id}/download` - Download file (Owner or recipient)
- `PUT /files/{id}/rename` - Rename file
- `PUT /files/{id}/move` - Move file to folder
- `DELETE /files/{id}` - Delete file
- `POST /files/{id}/share` - Create random share token link
- `GET /files/share/{token}` - Download file using share token
- `DELETE /files/share/{token}` - Revoke share link
- `GET /folders/` - List folders
- `POST /folders/` - Create folder
- `PUT /folders/{id}/rename` - Rename folder
- `DELETE /folders/{id}` - Delete folder
- `GET /files/storage` - Storage metrics & category byte breakdown
- `GET /activity` - Audit activity history

## 15. File Upload Workflow
1. User selects file on `upload.html` or drops into upload dropzone.
2. Frontend sends multipart POST request to `/files/upload` with Bearer token.
3. Backend validates filename (sanitizing path traversal), measures byte size, writes unique file to disk (`uploads/<uuid>.<ext>`), and inserts record in MySQL `files` table.
4. Backend triggers `analyze_file()` using Gemini 3.6 Flash.
5. AI output (summary, description, tags, insights) is saved into `ai_analysis` table.
6. `UPLOAD` action is logged to `activity_logs` table.
7. Frontend displays upload metadata and rendered AI analysis cards.

---

## 16. Folder Workflow
1. User creates folder on `folders.html`.
2. Backend validates folder name and checks duplicate folder names for the user.
3. Files can be assigned to folders during upload or moved via File Move popup.
4. Deleting a folder unassigns contained files (`folder_id = NULL`) so files are retained safely in Root Storage.
5. Actions (`FOLDER_CREATE`, `FOLDER_RENAME`, `FOLDER_DELETE`) are logged to activity history.

---

## 17. File Sharing Workflow
1. User selects file and chooses Public Link or Specific User Email.
2. Backend generates unpredictable 128-bit random token (`uuid.uuid4().hex`) stored in `file_shares` table.
3. Share URL generated: `http://127.0.0.1:8000/files/share/<token>`.
4. When accessed:
   - For Public Links: file download is served immediately.
   - For Specific User Shares: recipient must be logged in with matching email address; otherwise HTTP 403 Forbidden is returned.
5. Revoking share invalidates link immediately. `SHARE`, `SHARE_ACCESS`, `SHARE_REVOKE` logged to history.

---

## 18. Storage Dashboard
- `dashboard.html` & `storage.html` fetch dynamic metrics from `/files/storage`.
- Displays: Total Storage (15 GB free capacity), Used Storage (calculated sum of file sizes), Remaining Storage, Total File Count.
- Displays category byte breakdowns for Documents, Images, Videos, Audio, Code, and Other files.

---

## 19. Activity Tracking
- Tracks 13 distinct audit events: `UPLOAD`, `DOWNLOAD`, `VIEW`, `DELETE`, `RENAME`, `MOVE`, `SHARE`, `SHARE_ACCESS`, `SHARE_REVOKE`, `LOGIN`, `LOGOUT`, `FOLDER_CREATE`, `FOLDER_DELETE`.
- Displayed in reverse chronological order on `activity.html` with action badges, filenames, timestamps, and details.

---

## 20. Generative AI
- Powered by `gemini-3.6-flash`.
- Extracts readable content from `.pdf` (via `pypdf`), `.docx` (via `python-docx`), `.txt`, `.csv`, `.json`, `.md`, and code files (`.py`, `.js`, `.java`, `.cpp`, `.html`, `.sql`).
- Directly analyzes multimodal files (`.jpg`, `.png`, `.mp3`, `.wav`, `.mp4`).
- Generates:
  - **Summary**: Concise contents outline
  - **Description**: Purpose & nature of file
  - **Smart Tags**: 5 to 8 content keywords
  - **Insights**: Key topics, extracted visual text/numbers, tables, speaker details.
